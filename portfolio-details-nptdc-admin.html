NPTDC Business License Administration System

Project information

  • Category: Web Application
  • Client: Naypyitaw Development Committee

I developed an internal administration system designed to manage and process business license applications submitted through the public portal. The system provides a structured, multi-stage workflow that allows administrators to review, verify, and approve applications efficiently. The platform supports various types of applications, including new license requests, license renewals, license modifications, and license cancellations submitted by the public. Administrators can systematically validate application data, perform step-by-step approvals, and calculate applicable licensing fees based on predefined rules and regulations. Additionally, the system includes functionality for importing legacy license data using XLSX files, enabling seamless migration and integration of existing records into the new system. It also supports the generation of annual reports and facilitates the final issuance of official license cards upon successful approval. The admin interface was designed with a focus on usability and operational efficiency. The frontend was developed using the Angular framework, while the backend services were implemented using PHP to provide robust RESTful APIs for data processing and system integration.

Technical Stack:

  • Frontend: Angular (TypeScript, HTML, CSS, Kendo UI)
  • Backend: PHP (RESTful API Development)
  • Database: MySQL
  • API Integration: RESTful Services for data communication
  • Core Features: Multi-step approval workflow, fee calculation, XLSX data import, reporting system, license card issuance
  • Version Control: Git
  • Tools & Technologies: Visual Studio Code, Postman

This project demonstrates my expertise in building enterprise-level administrative systems, with a strong focus on workflow automation, data management, and system scalability.
