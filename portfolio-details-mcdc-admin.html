MCDC Business License Administration System

Project information

  • Category: Web Application
  • Client: Mandalay City Development Committee

I developed an internal administration system designed to manage and process business license applications submitted through the public portal. The system supports a structured workflow where administrators can review, verify, and approve applications in multiple stages. The platform handles various types of applications, including new license requests, license renewals, license modifications, and license cancellations submitted by the public. Administrators are able to systematically validate application data, perform approval processes, and calculate applicable licensing fees based on predefined rules. In addition, the system provides functionalities for generating annual reports and issuing final license certificates/cards upon successful approval. The solution was built to improve operational efficiency, ensure data accuracy, and streamline the overall license management process.

Technical Stack:

  • Frontend: Angular (TypeScript, HTML, CSS, Kendo UI)
  • Backend: PHP (RESTful API Development)
  • Database: MySQL
  • API Integration: RESTful Services for data communication
  • Version Control: Git
  • Tools & Technologies: Visual Studio Code, Postman

This project demonstrates my ability to design and develop enterprise-level administrative systems, focusing on workflow management, data processing, and system scalability.
