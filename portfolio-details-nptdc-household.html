NPTDC Household Management System

Project information

  • Category: Web Application
  • Client: Naypyitaw Development Committee

I developed a comprehensive Household Management System designed to manage and maintain detailed records of residential properties. The system stores essential household information and categorizes properties based on their type, enabling structured data management and analysis. Based on the classification of each household, the system calculates applicable taxes according to predefined rules and regulations. It ensures accurate tax assessment by considering different property types and their corresponding tax obligations. The platform also includes functionality for importing legacy household data using XLSX files, allowing efficient migration of existing records into the system. In addition, it supports the generation of annual reports, providing valuable insights for administrative and decision-making purposes. The administration interface was designed with a focus on efficiency and usability. The frontend was developed using the Angular framework to deliver a responsive and user-friendly experience, while the backend services were implemented using PHP, providing RESTful APIs for data processing and system integration.

Technical Stack:

  • Frontend: Angular (TypeScript, HTML, CSS, Kendo UI)
  • Backend: PHP (RESTful API Development)
  • Database: MySQL
  • API Integration: RESTful Services for data communication
  • Core Features: Household data management, tax calculation, XLSX data import, reporting system
  • Version Control: Git
  • Tools & Technologies: Visual Studio Code, Postman

This project highlights my ability to develop data-driven administrative systems, with a strong emphasis on data accuracy, automation, and scalability.
