NPTDC Business License Registeration System (Public Portal)

Project information

  • Category: Web Application
  • Client: Naypyitaw Development Committee
  • Project URL: app.nptdc.gov.mm/businesslicense

I developed a public-facing web application that enables users to conveniently submit applications for various types of business licenses. The platform is designed to provide an accessible and user-friendly interface for applicants to complete and manage their submissions online. The system supports multiple license categories, including restaurant business licenses, guesthouse/accommodation licenses, general business licenses, mobile vending licenses, and standalone advertising signboard licenses. Each application type is structured with specific requirements to ensure accurate data collection and compliance with regulatory standards. During the development of the public portal, I focused on creating a responsive and intuitive user experience. The frontend was built using the Angular framework, while the backend services were developed using PHP to handle application processing, validation, and data management through RESTful APIs.

Technical Stack:

  • Frontend: Angular (TypeScript, HTML, CSS)
  • Backend: PHP (RESTful API Development)
  • Database: MySQL
  • API Integration: RESTful Services for data communication
  • Core Features: Online application forms, multi-license support, data validation, API integration
  • Version Control: Git
  • Tools & Technologies: Visual Studio Code, Postman

This project highlights my experience in developing scalable and user-centric web applications, with a strong emphasis on frontend usability and backend integration.
